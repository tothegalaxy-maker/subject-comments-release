# 교과 평어 자동화 프로그램

초등학교 교과 평가자료를 바탕으로 학생별 평어를 관리하고, 학교생활기록부 작성에 활용할 평어 초안을 정리하는 Windows 프로그램입니다.

## 주요 기능

- **평가자료 불러오기:** 과목별 Excel(XLSX) 파일 업로드
- **평어 생성 지원:** Google Gems를 활용한 평어 생성 및 CSV 가져오기
- **평어 관리:** 학생별 평어 자동 배정, 선택, 직접 수정
- **초기화:** 과목별 학생 평어 초기화 및 평어 뱅크 초기화
- **작업 저장:** 프로젝트 파일(`.scproj`) 저장 및 불러오기
- **결과 저장:** 학생별 평어, 최종 평어, 전체 평가자료 등 Excel 파일 3종 생성
- **업데이트:** 최신 프로그램 버전 확인 및 Gem 스킬 ZIP 다운로드

## 다운로드 및 사용 방법

1. [Releases](https://github.com/tothegalaxy-maker/subject-comments/releases)에서 최신 Windows 프로그램을 다운로드합니다.
2. 압축을 해제하고 `SubjectComments.exe`를 실행합니다.
3. 과목별 평가자료를 업로드합니다.
4. 필요한 경우 프로그램에서 Gem 스킬을 다운로드하여 Google Gems에 등록합니다.
5. 생성한 평어 CSV를 불러와 학생별 평어를 배정하고 수정합니다.
6. 최종 결과를 Excel 파일로 저장합니다.

## 사용 시 유의사항

학생생활기록 작성 및 관리지침에 따라 교사는 학생을 직접 관찰하고 평가한 내용을 근거로 자료를 입력해야 합니다.

본 프로그램은 **평어 초안 작성을 돕는 보조 도구**입니다. 반드시 학생의 실제 수행과 평가 결과를 바탕으로 내용을 확인하고 수정하여 활용하시기 바랍니다.

## 버전 및 배포

- 최초 정식 버전: **v1.0.0**
- 지원 환경: Windows
- [최신 버전 다운로드](https://github.com/tothegalaxy-maker/subject-comments/releases)

프로그램은 GitHub Releases를 통해 배포합니다.

# 교과 평어 자동화 프로그램 Q&A
**자주 묻는 질문 (FAQ)**

## 1. 프로그램 설치 및 실행

**Q1. 프로그램을 설치해야 하나요?**

별도의 설치 과정 없이 배포된 ZIP 파일의 압축을 해제한 후 `SubjectComments.exe` 파일을 실행하면 됩니다.

**Q2. 어떤 컴퓨터에서 사용할 수 있나요?**

Windows 운영체제에서 사용할 수 있도록 제작된 프로그램입니다. macOS나 태블릿 환경은 지원하지 않습니다.

**Q3. 실행할 때 Windows에서 보안 경고가 나타납니다.**

개인 개발 프로그램은 Windows에서 게시자를 확인하지 못해 보안 경고가 표시될 수 있습니다. 공식 배포 저장소에서 다운로드한 파일인지 확인한 후 실행 여부를 결정해 주세요. 보안 경고가 나타난다는 사실만으로 프로그램이 안전하다고 판단할 수는 없습니다.

**Q4. 인터넷에 연결되어 있어야 하나요?**

평가자료 관리, 평어 수정, 엑셀 출력 등 기본적인 작업은 인터넷 연결 없이 사용할 수 있습니다. 다만 프로그램 업데이트 확인과 Gem 스킬 다운로드에는 인터넷 연결이 필요합니다. Google Gems를 이용한 평어 생성에도 인터넷 연결이 필요합니다.

## 2. 평가자료 업로드

**Q5. 평가자료는 어떤 파일 형식으로 준비해야 하나요?**

엑셀 파일(`.xlsx`)을 사용합니다. 프로그램이 인식할 수 있는 평가자료 양식과 항목 구성을 유지해 주세요.

**Q6. 여러 교과의 평가자료를 사용할 수 있나요?**

네. 국어, 사회, 도덕, 수학, 과학, 실과, 체육, 음악, 미술, 영어 등 10개 교과의 평가자료를 관리할 수 있습니다.

**Q7. 평가자료를 업로드했는데 일부 내용이 표시되지 않습니다.**

엑셀 파일의 열 이름, 평가 영역, 데이터 입력 상태 등이 프로그램에서 요구하는 형식과 일치하는지 확인해 주세요. 특히 셀 병합이나 임의로 변경한 양식이 있다면 원본 양식으로 다시 확인하는 것이 좋습니다.

## 3. 평어 생성 및 관리

**Q8. 프로그램이 평어를 자동으로 만들어 주나요?**

프로그램 자체에서 AI 평어를 생성하는 방식은 아닙니다. Google Gems를 활용하여 평어를 생성하고, 생성된 CSV 파일을 프로그램으로 가져와 관리하는 방식입니다.

**Q9. Google Gems는 반드시 사용해야 하나요?**

AI를 활용해 새로운 평어를 생성하려면 Google Gems를 이용할 수 있습니다. 다만 이미 준비된 평어 데이터가 있다면 프로그램에서 이를 관리하고 학생에게 배정하는 작업은 별도로 진행할 수 있습니다.

**Q10. Gem 스킬 ZIP은 무엇인가요?**

Google Gems에서 교과 평어를 생성할 때 사용하는 지침과 문체 예시가 포함된 파일입니다. 프로그램의 정보 탭에서 다운로드할 수 있습니다.

**Q11. 생성한 평어는 어떻게 프로그램에 가져오나요?**

Google Gems에서 프로그램에 맞는 CSV 파일을 생성한 후, 평어 관리 탭의 CSV 가져오기 기능을 이용하면 됩니다.

**Q12. 평어를 학생들에게 자동으로 배정할 수 있나요?**

네. 평어 데이터가 준비되면 자동 배정 기능을 통해 학생별 평어를 배정할 수 있습니다. 배정 후에는 내용을 확인하고 수정할 수 있습니다.

**Q13. 자동 배정된 평어를 직접 수정할 수 있나요?**

네. 평어를 선택 목록에서 변경하거나 해당 평어를 더블클릭하여 직접 수정할 수 있습니다.

**Q14. 직접 수정한 평어도 초기화되나요?**

초기화 기능에 따라 다릅니다.

- **평어 은행 초기화:** 평어 은행과 자동 배정된 평어를 초기화하며, 교사가 직접 수정한 평어는 유지됩니다.
- **전체 학생 평어 초기화:** 현재 선택한 교과의 모든 학생 평어를 초기화하며, 직접 수정한 평어도 삭제됩니다. 평어 은행은 유지됩니다.

초기화 전에 대상 교과와 기능을 반드시 확인해 주세요.

**Q15. 특정 교과의 평어만 다시 배정할 수 있나요?**

네. 교과별로 평어를 관리할 수 있으며, 현재 선택한 교과의 학생 평어를 초기화한 후 다시 배정할 수 있습니다.

## 4. 저장 및 이어서 작업하기

**Q16. 작업 중인 내용을 저장할 수 있나요?**

네. 프로그램의 프로젝트 파일(`.scproj`)을 이용해 작업 내용을 보관하고, 나중에 다시 불러와 이어서 작업할 수 있습니다.

**Q17. 다른 컴퓨터에서도 작업을 이어서 할 수 있나요?**

프로젝트 파일을 다른 컴퓨터로 옮긴 후 해당 컴퓨터의 프로그램에서 불러오면 작업을 이어서 진행할 수 있습니다.

**Q18. 프로그램을 업데이트하면 기존 작업 내용이 사라지나요?**

프로그램 업데이트와 프로젝트 파일은 별도로 관리됩니다. 다만 중요한 작업 내용은 업데이트 전에 프로젝트 파일로 저장하고 백업하는 것을 권장합니다.

**Q19. 학생 개인정보를 입력해도 되나요?**

학생 이름 등 개인정보가 포함된 자료는 학교의 개인정보 보호 지침에 따라 관리해야 합니다. 특히 외부 AI 서비스인 Google Gems에 자료를 입력할 때는 학생의 실명이나 개인 식별정보를 제외하고, 익명화된 자료를 사용해 주세요.

## 5. 엑셀 파일 출력

**Q20. 완성된 평어는 어떤 형태로 출력되나요?**

다음 세 가지 엑셀 파일로 출력할 수 있습니다.

| 출력 파일 | 내용 |
|---|---|
| `교과평어_학생별평어.xlsx` | 학생별로 10개 교과의 평어 정리 |
| `교과평어_최종평어.xlsx` | 교과별 시트로 최종 평어 정리 |
| `교과평어_전체평가자료.xlsx` | 교과별 평가자료와 평어를 상세하게 정리 |

**Q21. 엑셀 파일을 출력한 후에도 내용을 수정할 수 있나요?**

네. 출력된 파일은 일반적인 엑셀 파일이므로 Excel 등 호환 프로그램에서 수정할 수 있습니다. 다만 출력 파일에서 수정한 내용이 프로그램의 프로젝트 파일에 자동으로 반영되지는 않습니다.

**Q22. 엑셀 파일을 출력했는데 평어가 비어 있습니다.**

해당 교과 또는 평가 영역에 평어가 배정되어 있는지 확인해 주세요. 평어 관리 탭에서 학생별 배정 상태를 확인한 후 다시 출력하면 됩니다.

## 6. 오류 해결 및 업데이트

**Q23. 프로그램이 실행되지 않습니다.**

압축파일을 완전히 해제했는지, Windows에서 실행하고 있는지 확인해 주세요. 문제가 계속되면 오류 메시지와 발생 상황을 확인한 후 개발자에게 전달해 주세요.

**Q24. CSV 파일을 가져오지 못합니다.**

CSV 파일이 프로그램에서 요구하는 형식인지 확인해 주세요. 특히 열 이름, 데이터 구조, 파일 인코딩 등이 달라지면 정상적으로 불러오지 못할 수 있습니다. 가능하면 제공된 Gem 스킬로 생성한 CSV 파일을 사용해 주세요.

**Q25. 새 버전이 있는지 어떻게 확인하나요?**

프로그램의 정보 탭에서 업데이트 확인 기능을 이용하면 됩니다. 새로운 버전이 있는 경우 배포 저장소의 Releases 페이지에서 다운로드할 수 있습니다.

**Q26. 프로그램이 자동으로 업데이트되나요?**

아니요. 업데이트 확인 기능으로 새 버전의 존재를 확인할 수 있지만, 새 프로그램 파일은 사용자가 직접 다운로드해야 합니다.

**Q27. 오류를 발견하거나 개선 의견이 있으면 어떻게 하나요?**

오류가 발생한 작업 단계, 오류 메시지, 프로그램 버전을 함께 전달해 주세요. 학생 개인정보가 포함된 파일이나 화면은 개인정보를 제거한 후 공유해 주세요.
